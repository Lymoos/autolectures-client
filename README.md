# Автолекции — клиент

## Предупреждение SmartScreen при запуске

«Windows protected your PC… Unknown publisher» — это не про вирусы: SmartScreen ругается на любой exe без цифровой подписи, у которого ещё нет репутации. Полностью убирает предупреждение только сертификат code signing, остальное лишь снижает подозрительность.

Что уже сделано без сертификата: у exe есть иконка, название, версия, издатель и манифест (`versioninfo.json` + `assets/`), рядом с релизом лежит `.sha256`, а автообновление подменяет файл само — без метки «скачано из интернета», поэтому предупреждение бывает только при первом ручном скачивании.

Варианты подписи:

- **Azure Trusted Signing** — ~$10/мес, подписывает прямо из Actions. Нужна подтверждённая организация (для физлиц доступно не везде). Самый дешёвый рабочий путь.
- **Certum Open Source Code Signing** — ~€100 за 3 года, выдают физлицам, ключ на карте-токене. «Unknown publisher» уходит сразу, репутация копится дальше.
- **EV от DigiCert / Sectigo / GlobalSign** — $250-400/год, репутация SmartScreen с первого релиза, только для организаций.

С 2023 года ключ обязан лежать на токене или в облачном HSM, так что подписывать в CI можно только через облачный сервис — обычный .pfx в секретах больше не подойдёт.

Пока подписи нет: «Подробнее» → «Выполнить в любом случае», либо снять метку заранее:

```powershell
Unblock-File .\autolectures-windows-x64.exe
```

## Обновления

Клиент проверяет релизы GitHub при каждом запуске и раз в шесть часов. Если вышла версия новее, он ставит её сам: показывает окно «Обновление до X.Y.Z» с прогрессом, сверяет SHA-256, подменяет exe и перезапускается уже обновлённым — нажимать ничего не нужно.

Посреди лекции клиент не обновляется: пока запущена сессия, обновление откладывается и ставится сразу после её остановки. Кнопка «Обновить» в панели заголовка остаётся для ручного запуска.

## Сборка

```powershell
.\build.ps1                       # dist\autolectures.exe
.\build.ps1 -Release -Version 1.0.5
```

`build.ps1` сначала пересобирает `resource_windows_amd64.syso` (иконка, манифест, свойства файла) через `scripts\versioninfo.ps1`; `goversioninfo` подтягивается сам, если его нет в `GOPATH`.
